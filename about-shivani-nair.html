Who is Shivani Nair?

Shivani Nair is a dedicated Backend Software Developer with over two years of experience designing, building, and scaling system infrastructures that power business-critical applications. Specializing in Node.js and PHP architectures, she has successfully engineered solutions that improve application reliability, secure sensitive user data, and streamline workflows.

With a firm academic foundation in Computer Applications and early industry experience, Shivani approaches backend engineering not just as code implementation, but as a discipline of structural architecture. From optimized SQL query tuning to third-party integrations, she ensures that systems remain scalable, secure, and maintainable.

The Coding Journey & Education

Shivani's journey into software engineering started with her academic pursuits. She earned a Bachelor of Computer Applications (BCA) degree, which provided a thorough theoretical grounding in algorithmic structures, database systems, and software engineering methodologies. Driven by a desire to master complex architectures, she followed this with a Master of Computer Applications (MCA) degree, specializing in advanced database designs, network protocols, and distributed computing.

During her academic path, she was selected for the prestigious PwC Launchpad program, an experience that bridged academic frameworks and professional realities. This program honed her skills in enterprise practices, automated system testing, and clean architecture standards, preparing her for fast-paced professional engineering environments.

Professional Experience

In her current role as a Software Developer at Team Inertia Technology, Shivani plays a vital role in designing server-side structures. She develops RESTful APIs using PHP and Express.js, designs robust MySQL and PostgreSQL databases, and handles the continuous delivery workflows that keep services running smoothly for active clients.

Her day-to-day work includes integrating secure payment systems, processing cloud storage uploads (such as AWS S3 and DigitalOcean Spaces), managing JWT authentication scopes, and automating background jobs using cron schedulers.

Prior to this, she gained hands-on development experience as a Software Engineer Intern at Reputes Business Solutions. There, she was responsible for developing a Golf Tournament Management System, leveraging Google Apps Script to automate operations, player groupings, and real-time score calculation dashboards, dramatically reducing manual overhead.

Key Engineering Accomplishments

Shivani has built and contributed to several production projects that solve actual business challenges:

  • Deltin Transport & Fleet Management: Designed backend logistics models and APIs in PHP to coordinate driver allocations, transport approvals, and staff scheduling, resulting in a streamlined travel workflow.
  • Splitwise Clone: Engineered a robust Node.js financial engine, utilizing JWT encryption models to secure balance sheet settlements, group management systems, and transaction histories.
  • Garima Period Tracker: Programmed secure health-tracking micro-APIs inside Node.js, ensuring highly secure transmission of health indicators and automated scheduler alerts.
  • Deltin Ticketing & Invoicing: Developed Quotation and Proforma invoice engines that automated customer rates, invoice generations, and CSV/PDF export workflows.
  • ESG Event Planner CRM: Built task scheduling and allocation modules, complete with Google Calendar integration and automated SMTP email alerts to improve project transparency.

Engineering Philosophy

Shivani believes that backend code should be invisible to the user but absolutely dependable to the business. To achieve this, she prioritizes writing highly performant, self-documenting code and optimizing databases to handle load spikes. She uses Postman for automated API regression testing and integrates version control workflows through Git and GitHub to maintain transparent build histories.

Whether modeling data relationships in SQL, setting up Docker layers, or optimizing script execution times, Shivani Nair is committed to building secure, performant, and clean backend infrastructure.
